Alerta diário de vagas com n8n e IA

n8nAPI da GroqTelegramJavaScript
Problema
Mesmo com as vagas reunidas num só lugar, eu ainda precisava ler uma por uma para saber quais combinavam com o meu perfil.
Solução
Um fluxo no n8n que roda todo dia às 15h, lê as vagas coletadas nas últimas 24 horas e manda um resumo pelo Telegram. Uma regra fixa no código descarta vagas de ensino médio e de curso técnico. Depois, a IA classifica cada vaga como alta, média ou baixa compatibilidade.
O que aprendi validando a IA
Nos testes, a IA cometeu erros, como classificar uma vaga de curso técnico com um motivo inventado. Quando ajustar as instruções não resolveu, a regra passou para o código, porque uma regra fixa não erra o que já está decidido.

Plataforma de busca de vagas de estágio

PythonSQLiteStreamlitGitHub Actions
Problema
Procurar estágio exigia abrir vários sites todos os dias. Eu passava cerca de 6 horas por dia nisso.
Solução
Uma coleta automática que roda todo dia no GitHub Actions, busca vagas de estágio no Rio de Janeiro pela API da Adzuna, remove duplicadas e mostra tudo num site com filtros. Pela minha estimativa, o tempo de busca caiu para cerca de 3 horas por dia.
Destaque
A chave da API fica guardada nos segredos do GitHub e nunca aparece no código. Os dados coletados também alimentam o alerta diário com IA.

Agente de tratamento de dados e dashboard de vendas

PythonpandasHTML e JavaScriptGitHub Pages
Problema
Uma planilha de 100 vendas tinha datas impossíveis, datas no futuro e vendas canceladas misturadas aos dados válidos. Um gráfico feito em cima dela mostraria números errados.
Solução
Um agente em Python que aplica as regras de um schema, separa os problemas e gera um relatório de qualidade. Foram 24 datas impossíveis, 20 datas futuras e 5 vendas canceladas. O dashboard usa só os 51 registros válidos.
